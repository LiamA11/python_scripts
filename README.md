# Python Beginner Projects

This repository contains small Python projects I built while learning programming.
The goal was to practice logic, user input, and basic game mechanics.


## Projects

### Number Guesser
A simple terminal game where the user has to guess a randomly generated number.

Features:
- random number generation
- input validation
- attempt counter

### Rock Paper Scissors
A terminal game where the player competes against a computer opponent.

Features:
- random AI choices
- win/loss logic


## Learning Goals

- practice Python basics
- improve logical thinking
- learn how to structure small programs
